01 / SYSTEM

Built From Scratch.

ValaOS is a custom 32-bit x86 operating system developed from the ground up using C and x86 Assembly.

The project explores low-level operating system concepts including booting, protected mode, memory management, paging, interrupts, scheduling, user-mode execution, system calls and persistent storage.

02 / FEATURES

System Capabilities

01

Memory Management

Physical memory tracking, allocation and memory statistics.

02

Paging

Virtual memory mapping and x86 page permission handling.

03

Interrupts

Hardware and software interrupt handling through the IDT.

04

Hardware Timer

Timer-driven system ticks used by the scheduler.

05

Task Scheduler

PID-based task management and timer-driven context switching.

06

Ring 3 User Mode

User programs execute outside kernel privilege level.

07

System Calls

User programs communicate with the kernel through system calls.

08

Persistent VFS

Files and directories are stored on persistent disk-backed storage.

09

Program Loader

User programs are loaded directly from the ValaOS filesystem.
